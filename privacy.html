Privacy Policy

Last updated: 2026-05-04

This is a single-user, self-hosted application. The operator uses it only to manage their own social accounts. There are no third-party users of this service.

1. What is collected

This static website (the page you are reading) does not collect, log, or store any visitor data. There are no analytics, no cookies, and no tracking pixels.

2. Application data

The associated Postiz application stores, on the operator's own server only:

  • OAuth tokens for social accounts the operator has connected
  • Scheduled posts authored by the operator
  • Media files uploaded by the operator for publishing

This data is never shared, sold, or transmitted to third parties beyond the destination social platforms required to publish a post.

3. Third-party platforms

When the application publishes a post, the post content and the operator's OAuth token are sent to the destination platform's API (TikTok, Meta, X, LinkedIn, etc.). Each platform's own privacy policy governs that data once received.

4. Data retention

Application data is retained on the operator's local infrastructure until the operator deletes it. Disconnecting a social account in the application revokes its OAuth token and removes it from local storage.

5. Security

The application runs in Docker containers on the operator's local machine, behind a private tunnel. No public access is granted to other users.

6. Children

This application is not directed at children under 13.

7. Changes

This policy may be updated. Updates appear on this page with a new "Last updated" date.
